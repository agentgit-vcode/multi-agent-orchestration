┌─ WEB INTERFACE ───────────────────────────────────────────────────────┐

│  Step 1: Type your question in the text area                          │
│  Step 2: Select a template (optional)                                 │
│  Step 3: Click "Submit Question"                                      │

┌─ API ENDPOINTS ───────────────────────────────────────────────────────┐
│                                                                        │
│  Health Check:                                                         │
│    GET /api/health                                                    │
│                                                                        │
│  List Templates:                                                       │
│    GET /api/templates                                                 │
│                                                                        │
│  Get Template Content:                                                 │
│    GET /api/template/{name}                                           │
│                                                                        │
│  Submit Question:                                                      │
│    POST /api/ask                                                      │
│    Body: {"question":"...", "template":"..."}                         │
│                                                                        │
│  Get Task Result:                                                      │
│    GET /api/task/{task_id}                                            │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘

┌─ CURL EXAMPLES ───────────────────────────────────────────────────────┐
│                                                                        │
│  Check server:                                                         │
│    curl http://localhost:5000/api/health                              │
│                                                                        │
│  Submit question:                                                      │
│    curl -X POST http://localhost:5000/api/ask \                       │
│      -H "Content-Type: application/json" \                            │
│      -d '{"question":"What is AI?"}'                                  │
│                                                                        │
│  With template:                                                        │
│    curl -X POST http://localhost:5000/api/ask \                       │
│      -H "Content-Type: application/json" \                            │
│      -d '{"question":"What is AI?", \                                 │
│            "template":"comprehensive_plan.txt"}'                      │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘

┌─ TROUBLESHOOTING ─────────────────────────────────────────────────────┐
│                                                                        │
│  Can't connect?                                                        │
│    → Is Flask running? Check: python web_app.py                       │
│    → Is port correct? Default is 5000                                 │
│                                                                        │
│  Templates not showing?                                                │
│    → Check: prompt_templates/ directory exists                        │
│    → Refresh browser: Ctrl+F5                                         │
│                                                                        │
│  Port already in use?                                                  │
│    → Change port in web_app.py (last line)                            │
│    → Or: netstat -ano | findstr :5000  (Windows)                      │
│                                                                        │
│  Agent errors?                                                         │
│    → Check Flask console output                                       │
│    → Verify all agent files exist                                     │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘

┌─ PYTHON API EXAMPLE ──────────────────────────────────────────────────┐
│                                                                        │
│  import requests                                                       │
│                                                                        │
│  response = requests.post('http://localhost:5000/api/ask', json={     │
│      'question': 'What is machine learning?',                         │
│      'template': 'technical_analysis.txt'                             │
│  })                                                                    │
│                                                                        │
│  result = response.json()                                             │
│  print(f"Task ID: {result['task_id']}")                               │
│  print(f"Status: {result['status']}")                                 │
│  print(f"Result: {result['result']}")                                 │
